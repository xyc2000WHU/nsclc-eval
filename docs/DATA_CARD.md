# 公开数据说明

版本：2026-10-12，人工分歧裁定后（post-adjudication）。JSON/JSONL 均为 UTF-8。

| 文件 | 内容与粒度 |
|---|---|
| questions.jsonl | 90 道题的题干、参考答案、选项、类型与来源 ID；删除逐字证据句、内部备注、审核人员信息 |
| answer_metadata.jsonl | 900 条作答的模型、题号、模式、token、成本、耗时、检索 ID、输入指纹；不含回答或检索原文 |
| judgements.jsonl | 450 条开卷作答的一号/二号正确性及忠实性标签；保留二号 v3 版本；**75 条分歧附 `human_adjudication` 与 `priority_p0`（19 条另有 `human_rationale`）**，其余 375 条标 `human_adjudicated: false`（=未进入分歧裁定流程，**不等于"从未人工审核"**）；全部 450 条另带 `human_spot_checked`，标记该条是否在 `human_spot_checks.jsonl` 的 90 条抽检内（**该文件的标签是裁定前抽检快照**，最新标签以 `human_adjudication` 为准） |
| human_spot_checks.jsonl | 90 条抽检的人工标签、抽样阶段（30 + 60）、错误类型与抽检表中人工预填的成因；**是裁定前抽检快照**（DeepSeek / NSCLC-057 在此记为"部分一致"，最新裁定为"不一致"，见 `judgements.jsonl`）；不含备注原文、回答和证据原文 |
| cause_adjudication.jsonl | 成因裁定 20 条（16 条来自成因待确认表 + 4 条抽检表人工直填）；`in_refused_answer_scope` 标记其中的 18 条"该答却拒答"条目；仅含客观结论与名次，不含库内 chunk id |
| cause_confirmation_out_of_scope.jsonl | 上述 20 条中超出"该答却拒答"口径的 2 条（回答不完整 / 数值错误），保留而未删除 |
| retrieval_review.jsonl | 90 道题的登记来源命中与裁判上下文充分性标签，来自历史日志 |
| trap_review.jsonl | 50 条陷阱回答的拒答复核标签 |
| batch_b_mcq_summary.json | 批次 B 的选择题汇总；本公开版没有该批次的逐条请求/回答 |
| source_documents.json | 文献本地标识、页数、切块数等元数据；不是全文或完整书目 |
| release_status.json | 发布状态、规模、裁定完成数、裁定后分布与知识库版本 |
| manifest.json | 公开文件 SHA256，用于检查快照内容是否变化 |

`fp` 与 `answer_input_fp` 是原工程的**作答输入指纹**，不是回答正文的内容哈希，不能仅凭它们证明回答正文完整或未改动。公开文件的 manifest 负责本次发布快照的字节完整性，也不构成真实性认证。

## 能复算什么

可以检查公开记录的唯一性、完整性、标签范围，重新计算标签一致率、分布、人工抽检样本内一致率、检索命中率与元数据成本。数据从本地实验记录按字段白名单导出，不是新生成的模型作答。

本版还可以复算：人工裁定分布（56/10/9，P0 16/2/0）、裁定后 450 条最终分布（334/19/97，口径见下）、"谁更准"（一号 30/75 = 40.0%、二号 v3 44/75 = 58.7% 的描述性命中数）、人工覆盖关系（90 条抽检 ∩ 75 条裁定 = 16 → 149/450 有独立人工正确性记录；375 条推定值中 74 条已抽检、301 条未人工审核）与成因裁定（18/18 在检索/上下文侧）。`scripts/verify_public_release.py` 会逐项断言这些数字；**它不做显著性判读**。

**分布口径**：450 条中 **375 条是两位 AI 裁判原本就一致的推定值**（一致 278 / 部分一致 9 / 不一致 88），只有 **75 条分歧**取人工裁定。因此"一致 334"里包含大量未经逐条人工确认的条目，不能读作经人工核验的医学准确率。这 375 条并非全部无人审核：**74 条另经分层人工抽检且抽检标签与双裁判标签相同（56 一致 + 18 不一致），301 条没有任何人工标签**。按（模型, 题号）去重，90 条抽检与 75 条裁定重叠 16 条，故有独立人工正确性记录的共 **149/450 = 90 + 75 − 16**；`human_adjudicated: false` 只表示"未进入分歧裁定流程"，**不等于"从未人工审核"**（覆盖情况看 `human_spot_checked`）。这不是随机、自加权的全体准确率验证。

**97 条的来源**：97 条"不一致" = 9 条分歧人工裁定结果 + 88 条双裁判一致结果（后者中 18 条接受过人工抽检）→ 按现有人工记录及最新裁定，27 条有人工"不一致"标签、70 条尚无人工标签。用于错误类型归类的 19 条是 75 条裁定中未获"一致"的条目（部分一致 10 + 不一致 9），**不是** 97 条的子集。

**抽检表的新旧版本关系**：`human_spot_checks.jsonl` 保留裁定前抽检快照，不无痕覆盖；DeepSeek / NSCLC-057 在该快照中为"部分一致"，最新裁定（`judgements.jsonl`）为"不一致"（理由"未给技术差异"）。应用最新人工标签后复算这 90 条：一号 81/90 = 90.0%（κ 0.757）、二号 v3 83/90 = 92.2%（κ 0.809）——这是**应用人工最新标签后的复算，不是重新判题**；最终 450 条的 334/19/97 不受影响。

## 不能单凭公开副本验证什么

无法重新审阅完整回答、逐句证据或裁判理由，也不能独立重建原始检索库。原始 PDF、知识库切块、完整上下文与回答可能包含第三方文献内容，故未打包；不能把本仓库描述为可一键逐字复现全部历史输出。

问题和参考答案是本项目的文献衍生评测材料，不是临床建议。来源 ID 用于本地追溯；文献授权和后续再分发须分别确认。本次没有自动为代码、题库或第三方材料套用 MIT/CC 许可证。

## 人工裁定更新

75 条正确性分歧已由项目负责人逐条裁定完毕（0 条空白），原始两位裁判标签**未被覆盖**：人工裁定写在 `judgements.jsonl` 的 `human_adjudication` 字段（19 条另附 `human_rationale`），成因裁定写在 `cause_adjudication.jsonl`。其余 375 条带 `human_adjudicated: false`，明确保持"未进入分歧裁定流程"的状态，不得当作已确认结论引用；其中 74 条另有抽检标签（`human_spot_checked: true`），**该字段为 false 不等于"从未人工审核"**。

成因裁定的口径限定：裁定对象是**出题时登记的那一段**是否进入上下文，**不等于**模型收到的片段中没有等效证据；"检索没给到"与"模型没读出"的定量拆分仍需对照实验（未做）。"谁更准"只作描述性报告（一号 30/75、二号 v3 44/75）：两位裁判评同一批回答且同题回答相关，**未做考虑配对结构与同题相关性的差异检验**，不能用区间重叠判断显著性。若后续题库、知识库或输入指纹变化，需要另加带日期与输入版本的裁定文件，并说明哪些旧判定失效。
