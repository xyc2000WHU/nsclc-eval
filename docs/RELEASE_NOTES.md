## 公开版与内部版测试差异

`regression_test.py --public` 跳过未公开生产资产的 8 项断言：5 个模型导出与原回答一致性检查、1 项真实导出存在性、2 项内部成因表检查。模拟数据的对应判据仍执行。没有使用 --public 时仍保留原检查条件；缺少生产材料的公开副本不应运行该模式。

本地检查通过不等于 GitHub Actions 通过。2026-10-12 首次云端检查：Ubuntu 通过，Windows 因 Git 检出时转换换行导致文件指纹不匹配而失败。2026-10-14 修复加入 `.gitattributes` 保留原始字节、为工作流设置 `PYTHONUTF8=1`，并同步主页流程图和闭卷未自动判分的说明。修复提交的实际云端状态以 [Actions](https://github.com/xyc2000WHU/nsclc-eval/actions) 为准。
